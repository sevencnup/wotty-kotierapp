# 首页节点菜单固定虚拟 IP 开发记录

## 目标

在首页节点列表每行的三点菜单中提供固定当前本机 EasyTier 虚拟 IP 和恢复 DHCP 的操作，让用户无需进入未接入主导航的独立配置页。

## 实施步骤

1. 将菜单操作接入首页 `ConfigRow`，不改变截图中现有“修改配置”和“删除配置”的位置与行为。
2. 仅当对应节点正在运行且已获取本机虚拟 IP 时启用“固定此 IP”；保存当前虚拟 IPv4，并将配置设为静态地址。
3. 静态地址配置显示“恢复 DHCP”；操作后持久化配置并提示下次启动生效。
4. 保证只有当前运行实例的本机虚拟 IP 能用于固定，不能误用其他实例或远端节点的地址。
5. CompactTopBar 背景覆盖状态栏安全区，并移除父容器重复的顶部留白；底部导航栏背景延伸覆盖系统手势条区域，不留底色间隙。
6. 暂不递增应用版本号，保持 `4.2.47 (4069)`。
7. 构建正式证书签名的测试 APK，保留旧 APK，并在已连接手机上安装和核对入口及导航布局。

## 验收标准

- 首页节点行的三点菜单包含与该配置状态相符的固定或恢复操作。
- 固定操作保存当前运行节点的本机虚拟 IPv4、关闭 DHCP；恢复操作开启 DHCP 并清除静态 IPv4。
- 修改只影响所选节点配置，菜单原有编辑和删除行为保留。
- APK 构建成功并可使用已安装应用的签名覆盖安装。
- 顶部状态栏安全区和底部手势条区域没有露出页面外层底色。

## 边界

- 固定的是 EasyTier 虚拟网络 IPv4，不会更改手机 Wi-Fi 地址。
- 固定地址从下一次启动生效，用户需自行确保地址在虚拟网络中唯一。
