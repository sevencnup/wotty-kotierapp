## 约束与验收

- 版本固定为 `4.2.47 (4069)`，禁止递增版本号。
- 本地 APK 必须使用项目固定的正式证书；私钥、密码、签名文件及其内容不得提交或输出。
- GitHub Release 标签为 `v4.2.47`，Release 正文包含可读更新内容和该版本下载链接。
- 正式包文件名带版本号和 versionCode，不覆盖已有安装包。
- 不推送任何提交到 GitHub 以外的远端。
