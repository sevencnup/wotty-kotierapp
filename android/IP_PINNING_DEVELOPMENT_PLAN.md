# 固定 EasyTier 虚拟 IP 开发计划

## 目标

在网络配置页启动并取得本机 EasyTier 虚拟 IPv4 后，提供一键固定当前地址的操作。固定地址写入当前网络配置，之后启动时关闭 DHCP 并使用该静态 IPv4；同时允许用户恢复自动分配。

## 实施步骤

1. 沿用 `NetworkConfig.dhcp` 和 `NetworkConfig.ipv4` 作为静态地址配置，不新增重复的持久化字段。
2. 在本机直连地址卡片中，DHCP 模式显示“固定此 IP”；固定模式显示状态及“恢复自动分配”操作。
3. 固定时保存当前运行态本机虚拟 IPv4，并设置 `dhcp = false`；恢复时设置 `dhcp = true` 并清空静态 IPv4。
4. 操作后立即持久化，并提示配置从下次启动生效；说明静态地址必须在虚拟网络内唯一。
5. 更新应用版本和版本记录，并编译 Android Kotlin 源码确认修改可编译。

## 边界

- 只固定 EasyTier 虚拟网 IP，不修改手机 Wi-Fi/蜂窝网络的物理局域网地址。
- 静态地址不会由客户端验证其在网络内是否唯一，用户需确保没有其他节点占用。
