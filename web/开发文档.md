# Kotier 官网页面开发文档

## 目标

在 Android 项目中新增一个独立的 TypeScript 网页入口，复刻给定的 Kotier 内网穿透官网视觉，并提供可点击的导航、下载、登录、注册和移动端菜单交互。

## 实施步骤

1. 创建 `web` Vite + TypeScript 子项目，并注册到根 `pnpm-workspace.yaml`。
2. 复用仓库 `images/web.png` 作为产品界面主视觉，建立蓝白配色、响应式栅格和页面字体层级。
3. 实现导航栏、首屏产品介绍、能力特性、工作原理、平台支持、行动区和页脚。
4. 添加移动端导航展开、平滑滚动、下载按钮反馈和当前导航状态。
5. 执行依赖安装、TypeScript 构建和页面运行检查，修正发现的问题。
6. 按项目约定记录 `0.0.1` 版本描述。
